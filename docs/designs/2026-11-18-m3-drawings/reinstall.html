Reinstall: The Install Script's Safety Flag Blocks It

Found by the design gate and checked in source. The install script (core §5.2) always sets talos.halt_if_installed=1, so a network boot never reinstalls over a working node by accident. Talos v1.12.11 halts when that flag is set and Installed() is true (v1alpha1_sequencer.go), and Installed() means the META partition exists (v1alpha1_state.go:226). Topf 70cdbc8's reset wipes only STATE and EPHEMERAL when --full is false (internal/cmd/reset/reset.go:21-23, 76-81), so META survives then. Corrected after design-gate pass 2: --full defaults to true (cmd/topf/reset.go, env TOPF_FULL), so a default topf reset already wipes META. The hazard below is topf reset --full=false; this page first said the default kept META, which was wrong.

Today's Design, Example talos-04-wrk

  1. topf reset --full=false → STATE and EPHEMERAL wiped, META kept
  2. hephaestus machine reinstall 52:54:00:e2:e0:03 --topf-reset-done → assigned
  3. ↓ reboot, network boot, row 10: install script with talos.halt_if_installed=1
  4. Talos sees META → halts. Every boot, forever. The recovery path M3 ships does not recover.
A · recommended

Keep The Flag; Reinstall Needs A Full Reset

  1. topf reset (default --full=true) → every partition wiped, META included
  2. machine reinstall 52:54:00:e2:e0:03 --topf-reset-full-done → assigned
  3. ↓ network boot, same install script as every install
  4. No META → Talos installs → installing
  • One install script; the flag still guards every other path into assigned
  • A reinstall starts from a clean disk, which is what a reinstall is for
  • The flag name says which reset was run, so the CLI cannot be satisfied by the wrong one
  • A full wipe of the system disk, not only STATE and EPHEMERAL
B

Drop The Flag After Reinstall Or Abort

  1. topf reset --full=false → META kept
  2. machine reinstall … --topf-reset-done → assigned, marked "entered by reinstall"
  3. Install script omits talos.halt_if_installed for that machine's next install
  4. Talos boots the network image and installs over the existing install
  • Also tolerates --full=false
  • Two script variants and a new "how it entered assigned" field
  • Installing over a kept META is unverified; it needs its own lab test
  • Removes the safety net exactly where a machine is known to hold an install

Either way, lab test 3 gains this reinstall case on real hardware.
