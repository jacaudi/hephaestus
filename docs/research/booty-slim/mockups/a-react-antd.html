What this tier means

  • A JS build stage (Bun) produces the bundle, which is embedded into the Go binary.
  • State lives in the browser: sorting, filtering and search run client-side, and live row updates arrive over a WebSocket or SSE into that state.
  • The UI is built from antd components: Table, Drawer, Tabs, Descriptions, Tree.
  • The design-tokens antd output exists today.
